# 光线系统


先指定光源位置与动机，再定情绪。自然光来自天窗/太阳/阴天；实用光为画内灯、火、屏幕；戏剧光强调轮廓；混合光要分主次，不让每一物件都发光。

| 光位 | 可见作用 | 风险与处理 |
|---|---|---|
| 顺光 | 面部和衣纹易读 | 容易扁平，用背景层次分开 |
| 侧光 | 强化体积与接触面 | 另一侧保留必要细节 |
| 逆光 | 分出轮廓与雨丝 | 不把主体曝光成纯黑 |
| 顶光 | 压肩、深眼窝 | 眼神关键时给自然反射 |
| 底光 | 异常、威胁候选 | 不默认等于邪恶 |
| 斜上侧光 | 面颊分区 | 不把伦勃朗术语直接当模型指令 |

硬光产生清楚影边，软光包裹皮肤，漫射压低反差，切割光只照某个区域。明暗比先用“亮侧可见、暗侧保衣纹”描述，实际灯光数值依工具实测；曝光优先保脸、手、刃口，不用死黑冒充高级。时间、情绪与空间通过光源高度/色温/遮挡变化体现，不用情绪词替代布光。

跨段记录主光所在世界方向、画面投影、冷暖、亮度档与画内光源。相机转向导致屏幕左右光变化不等于世界光源跳转。提示词例：“门外冷天光从人物左后方落入，桌边暖灯照亮持杯手指”。光向漂移先固定主光和参考；过曝收光源面积或后期；暗部死黑恢复局部可读性。调色不能补回原本不存在的细节。

## 动态光色与阴影推演（防“平铺直叙”）

- **画内光源的呼吸感**：场景已有无遮罩的烛火、油灯、火把，且人物或打斗引起的气流能到达火焰时，火苗轻微偏摆，相应阴影随光源变化；密闭灯罩、稳定电灯与无风场景不强行闪烁，不能为“电影感”新增频闪。
- **空间过渡**：从室外到室内，写清门打开后已有光源怎样切进地面、人物怎样进入较暗/较冷暖的区域；光比与色温差异确实存在时才强调骤变，连续相同光场不硬变色。保持光源世界方向，不把过门写成瞬移式曝光/肤色跳变。
- **轮廓分离**：暗背景里，用已有月光、火把、门窗反射或明度层次分出人物肩线、头发与兵器。采用边缘光时交代来源、方向和遮挡；若现场无可用边光，调整已有背景/主体明度或提出补光候选，不凭空加月亮或火把。

上述关系服务主动作和空间，轻微明暗/衣发变化共用原氛围额度；点灯、爆灯或移动光源若为独立事件必须计入原3+2。固定光位不算新动作，光效不得吞没脸、手、刃与接触区。
