# 萧烬压境·制作备注

本文件只供制作与验收，不进入提示词。对应[填写示例](萧烬压境_填写示例.md)；[原稿存档](萧烬压境_原稿存档.md)完整保留旧设计，不能作为新版输入直接粘贴。

## 本次设计条件与边界

示例采用无图、接受分段剪辑的条件。平台模式、请求档位、原生音频和首尾帧功能均未实测；G是事件单元，不等于平台可直接请求该净时长。各段实际GEN、素材文件和选用区间待生成后填写，不能把下面的建议当成已完成剪辑。

保持30秒、三处接触记忆点和结局：锤拳破防、双靴落瓦、巨剑压上花瓣；最终侧殿坍塌、双方震退。术法保持六瓣、三高三低错层和中空花心，尚未授权简化这些结构。

## 动作负荷与关键检查

| 单元/净长 | 必执行/氛围/禁止条数 | 主要交互与风险 | 可观察结果 |
|---|---|---|---|
| G01 / 2秒 | 2/1/1 | 包抄封路与中央逼近，兽群和身体容易互相遮挡 | 两翼封路可辨，萧烬进入拳距但未出拳 |
| G02 / 2秒 | 2/1/1 | 一次直拳架偏 | 同一拳、同一左前臂交汇，拳路偏出胸线 |
| G03 / 2秒 | 2/1/1 | 一次左摆拳与右臂护头 | 护臂抬高，夜宸渊后退 |
| G04 / 1秒 | 2/0/1 | 一次前臂抬防控制，肢体归属易混 | 左前臂压住对方右臂，防线升高 |
| G05 / 3秒 | 3/1/2 | 一次斜下重击，兼有空中高度转折与投影破碎，高风险 | 先拳臂接触，后防御受压与右下坠落；平推拳拒收 |
| G06 / 2秒 | 2/1/1 | 一次肩背撞檐，带建筑破坏 | 上层破口与下层落面同框，路径连续 |
| G07 / 3秒 | 3/1/2 | 一次落瓦承重与滑退，高风险 | 双靴先接触、膝部承重、臀部离瓦；坐滑拒收 |
| G08 / 3秒 | 2/1/1 | 一次低位兽影攻击与避让 | 前脚让过、兽影切瓦，人物未受击 |
| G09 / 2秒 | 2/1/1 | 断路造成反制准备；来敌扑落为并行威胁 | 后脚退路将失撑，左掌尚未触瓦 |
| G10 / 2秒 | 2/1/1 | 掌瓦接触并触发花瓣展开，雷击对手另段 | 掌触瓦在先，六瓣结构完整，雷流尚未推出 |
| G11 / 2秒 | 2/1/1 | 一次雷流命中与推开，不再重复拍瓦开花 | 胸肩先受推、身体随后退开，双方距离改变 |
| G12 / 2秒 | 3/1/2 | 一次远距剑劈与花阵承接，凝剑、制动、手位和倾花负荷较高 | 制动依据可辨、同一剑柄、刃压花瓣；若失败再拆凝剑与劈接 |
| G13 / 2.5秒 | 3/2/2 | 同一碰撞的承压—传力—释放—后果，破坏与位移并行，高风险 | 左掌经身体传力至木梁，梁先变形，后爆发与震退 |
| G14 / 1.5秒 | 2/1/1 | 反震制动后的局势交代 | 双方分离后稳住，花阵和地形缺口仍清楚 |

净长合计：2+2+2+1+3+2+3+3+2+2+2+2+2.5+1.5=30秒。此加总仅为设计预算。短单元可从更长原始素材净选；接缝、速度与连续性必须看片验证。

优先测试G05、G07及G10—G12的接触与结构。原G10的掌瓦/雷击复合交互已拆成G10拍瓦开花与G11雷流推敌；G12若仍因凝剑、制动和劈接过载，再拆凝剑与劈接。新单元仍查3+2与整次GEN负荷，不能只靠改名；本例仍待动态验证。

## 剪辑与接缝

- 每段生成后核对左右、朝向、动量、手位、术法、损毁；实际使用图像承接时，合格帧文件登记在生成输入的控制栏。
- G05尾尚未撞瓦；G06只撞上层檐一次；G07从接近下层瓦面承接，不能重复落地。
- 上檐破口、双靴长痕、兽影削断瓦脊按顺序保留；夜宸渊首次落瓦后的积尘与擦损持续。
- 以动作硬切起稿；不可用叠化遮掩手位、屋面或动量跳变。生成余量剪掉，总净长仍为30秒。
- 整体先按1.0×组织；若局部提速，保留接触与后果并重新核算净长。整体1.2×将变为25秒，不能仍称30秒。
- 接触成立后可试短促定向震动或局部亮闪；是否全屏白闪由可读性测试决定。它是后期选项，不进入本次生成输入。
- 末尾从约29.5秒选清楚构图，后期定格约0.5秒；选帧不得吞掉震退结果。生成输入只要求清楚末尾姿态，不要求模型执行后期定格。

## 声音保留与归属

以下均为设计提案，未制作、未试听。当前示例原生音频能力未确认，因此不把这些行放进可导出的生成区；若实际模式确认支持，可将选定事件写回对应G的原生音频行，其他任务继续留在本备注。

| 时间/单元 | 可原生生成的候选声音 | 后期任务 |
|---|---|---|
| 0—2 / G01 | 兽潮低频接近、衣料破风；萧烬短笑候选 | 控制低频遮蔽，不要求持续笑声 |
| 2—7 / G02—G04 | 拳路破风、护臂交汇、晶面摩擦、急促呼气 | 分清架偏、格挡和未命中，事件音头跟随实际接触 |
| 7—10 / G05 | 重击短撞、晶面受压破碎、下坠风切 | 重击音头在接触后，不能仅靠爆炸音补力度 |
| 10—15 / G06—G07 | 穿檐碎瓦断木、双靴压瓦、连续滑擦 | 将穿檐、落瓦、滑擦分清，不混为一声长爆炸 |
| 15—20 / G08—G09 | 追击脚步、兽影切瓦、椽条开裂 | 方位跟随左向右追退，开裂声提醒退路危险 |
| 20—24 / G10—G11 | G10掌触瓦与晶体悬展，G11电流与雷击；夜宸渊短台词“够了！” | 当前台词保留作后期配音候选；若改原生，写明夜宸渊在掌触瓦后、雷流推出前短促说出，并看片核同步 |
| 24—28.5 / G12—G13 | 凝剑低频、剑刃接晶面硬音头、气浪释放、梁柱断裂 | 先接触硬音头后爆发，材质破坏分层，控制低频堆叠 |
| 28.5—30 / G14 | 残余电流与碎瓦坠落 | 给收势和环境尾音空间，音乐编排另做 |

原生音频填法示意，仅在当前模式已确认支持后采用：G10可写`【原生音频】掌触瓦时响短裂声，六瓣展开时进入晶体声。`；G11可写`【原生音频】夜宸渊在雷流推出前短促说“够了！”，随后电流声随雷流出现。`。这行描述生成声音，不含混音、分轨、音量百分比或口型修整指令。

## 验收与适配记录

外观一致性、动态接触、原生能力、实际接缝、音轨、口型与手机观看均待验证。关键动作不通过即返工，不以气氛或精致人物抵消。

若空间错层不稳，先做结构参考/稳定构图小样；删掉三高三低、改变中空结构或花瓣数量属于设定变更，当前未授权。若平台只提供较长请求档位，先净选单事件素材；重新合并多个单元一次生成时，另查整次负荷，不默认原样合并即可执行。
