# 表演与微表情设计卡

供已启用[表演与心理动作系统](../../references/performance-and-psychology.md)时填写，是辅助设计卡，不改变主模板或导出结构。AI据现有剧情填卡，不让用户从零填写心理档案。

## 角色心理档案

```yaml
character: "人物及本场版本______"
current_objective: "此刻想从谁得到什么______"
obstacle: "已存在的障碍______"
action_verb: "恳求谁/掩饰什么/威吓谁______"
hidden_fear: "已有依据的隐忧/明确候选______"
physical_tell: "一个与动作相容的可见身体信号______"
```

## 表演提示词槽位

| 槽位 | 填写内容 | 自检 |
|---|---|---|
| 【视线轨迹】 | 起点______→终点______→变化时机（相对事件）______ | 目标真实在场、机位看得见；不强求精确毫秒 |
| 【面部微动作】 | 眼睑______；咬肌/下颌______；呼吸______ | 候选可留空，最终只选少量有效细节 |
| 【身体质感】 | 重心______；节奏______；与对方/出口的空间关系______ | 不与主打斗的支撑、抓持、持械冲突 |
| 【降级与分流】 | 肢体替代______；可选独立反应镜头/后期方案______ | 方案待用户接受，复杂心理与配音说明进备注 |
| 【验证状态】 | 已观察结果______；仍待测______ | 没有视频不填“表演已通过” |

## 填完后的输出模板（设计候选）

```text
动作反应候选：当______（已有触发）发生，______（角色）先______（可见注意/身体选择），随后______（当前目标要求的动作），停在______（可见状态）。
摄影候选：______（景别/角度）容纳______（必须看清的视线目标或身体部位）。
氛围候选：______（一个可弱化的生理细节，非决定性结果）。
制作备注：______（心理意图/复杂停顿/后期替代/待验项）。
```

“自动生成”指AI据已填卡生成候选文本，不是脚本执行，也不是自动批准新增动作。仅保留适合当前单元的候选：动作反应进入内部【必执行】，取景要求才可进入“单元摄影”，可弱化细节进入【氛围】；不把身体动作塞进摄影栏规避3+2。超预算先替换原空泛描述，或提出拆反应镜头的选项。

最终交给视频模型前，把所选候选融合进本段自足白话：首句补画风与角色外观，去卡名、G编号、工程标签和时间段；禁止项转为肯定画面约束。大动作段优先肢体信号，精细微表情段保持低身体运动，控制/管理信息仍在正文外。
