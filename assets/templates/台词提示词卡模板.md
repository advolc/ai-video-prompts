## 填充伪代码与判定逻辑（非导出流程）

```text
if 未获台词模块授权: 不载入本卡，继续普通设计
冻结剧情事实、人物知情边界、动作结果
内部填 intention / subtext / speech_action / style
if 缺项会改变已定事实: 只补问关键项，其他工作照常推进
else: 缺项可填明确候选，不伪称已定
写少量备选 -> 检查DNA与手法 -> 选一条
if 与身体动作/呼吸冲突: 缩句或提出移至动作空当/画外声的候选
if 实际未试读: readthrough_status = 待试读
台词深度卡整体 -> 制作备注/后期配音
if 本次已核原生对白且明确采用且短句需精确说出:
    只把选定短句与说话者、自然动作触发送生成层
else:
    视频只留可见情绪代理与简单口部动作，文字留后期
可见表演 -> 内部3+2负荷检查 -> 最终自足白话转写
```

填完不自动调用配音/口型工具，不声称已经试读或同步通过。最终默认只交可复制纯文本；仅用户主动索要工程检查时展示工程内容，不自动捆绑两版。本卡中的分析与YAML不进入平台正文。
