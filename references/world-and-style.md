# 战场建造与视觉风格

## 场地先支持行动

先用俯视草图或白模验证通路，再增加装饰。画出边界、角色起点、目标、入口/出口、高差、遮挡、可破坏物，以及摄影机需要的位置。用人物身高作尺度参照；追击需要距离，长武器需要回摆空间，巨型角色需要站立和转向空间。

### 场景落地的三层延展（防“名词化”）

用户选定古风酒馆、竹林、破庙等场景后，先把场景名落到陈设、布局和环境反馈，再进入动作或对话提示词。已有细节直接沿用，缺项用简短建议让用户选或自定，不逐件盘问，也不把建议当已定事实。

1. **陈设与道具**：桌凳材质，有无屏风、柱子或二楼，桌上已有何物；明确哪些物件承担文戏遮挡、手部反应或动作借力，不为凑细节凭空加兵器。
2. **空间布局**：出入口与门窗/油灯位置，角色在中心、靠墙还是死角；明确角色、光源、通路之间的关系，支持机位与走位。
3. **环境反馈**：漏风、潮湿或闷热具体影响什么，如帘角摆动、靴底水痕、碗口热气；声音底噪按实际原生能力或后期职责分流。

内部三层都检查，当前只取与本场选择相关的少量抓手；可以先给2—3个布局候选和一个关键问题。明确只要简短提示词时，用已知信息和可辨认候选起稿，不额外开陈设问卷。固定布景不占动作条数，新增可见交互仍计入原3+2，不隐藏在布景描述里。

| 场景层 | 设计问题 | 对打戏的影响 |
|---|---|---|
| 地面与支撑 | 湿滑、碎石、木板、低重力还是可飞行？ | 起步、制动、脚印、跌落和落点 |
| 通道与高差 | 哪条路快，哪里会被截断？ | 逼位、绕行、追击与脱身 |
| 遮挡与视线 | 谁能看见谁，何时失去目标？ | 伏击、误判、保护与远程射线 |
| 可交互物 | 扶手、门、柱、绳、机械装置承担什么动作？ | 借力、阻挡、改线与目标争夺 |
| 破坏层 | 触发阈值、破裂方向、碎块落点？ | 新障碍、新危险和不可逆的空间变化 |
| 天气与氛围 | 常态风雨与动作扰动怎样分开？ | 深度、速度参照、衣发和材料响应 |
| 视觉锚点 | 哪些轮廓/明暗块能跨镜头识别？ | 快切或大幅运动后重新定位 |

环境参与至少服务当前戏的具体需求，不强求每场大破坏。空旷平地可以突出距离与无处可躲；狭室可以突出贴身与夺门。不要为了“丰富”加入妨碍已定动作的道具。

## 环境物理与动态反馈（防“舞台剧背景板”）

环境反馈须来自当前已定天气、介质、材质与动作。为本段关键落脚/接触写清一项可见反馈，再按存在条件使用下列关系；这是因果检查，不是每段强制同时新增风、尘、雨和爆破：

- **风与气压**：已有风场时，衣摆、发梢与受风物的方向一致；大动作附近确有落叶/浮尘时，写明其被带起的路径。内力只有已建立气压作用且门窗处于作用范围时才可使其震动/作响，不把所有法术都写成震窗。
- **材质接触反馈**：关键每一步落脚都应有与地面匹配的反馈，如枯叶受压碎裂、湿泥下陷、薄水沿靴边挤开；硬地可用脚底承重与影子接地，不强制所有地面碎裂。同一连贯步行可一句建立持续的落脚规则，不逐步罗列出十条新事件；回声等音频按本次生成/后期分流。
- **流体与粒子**：场景已有雨水时，雨点落在既定刃面后沿表面溅开；已有近地雾时，身体经过后雾丝才被扰动。干燥裸地不凭空长出水雾、落叶或尘团，粒子反应不能早于动作触发。

优先把一个环境反馈写成主动作的直接后果，衣发/非关键粒子按原氛围额度取舍；独立破坏、物件位移或状态变化仍须计入原3+2，不能藏进“环境”绕过计数。参考与六项接缝继承既定风向、湿度、术法与损毁，声音未核支持时留制作备注，不删除可见物理关系。

## 建造顺序与交付

1. 功能布局：画通路、危险区和动作触点；明确实际尺度或相对尺度。
2. 粗建验证：用方块/平面/简单分层图验证人物通行与摄影机视线，标记有意穿墙的虚拟镜头及其空间解释。
3. 美术深化：依照主要镜头分配细节，接触物、近景材质和识别锚点优先；远处重复元素可复用。
4. 状态变体：完好、破坏、残留物对应镜头编号；碎片不能下一镜自动消失或堵住仍要通过的路。
5. 灯光检验：常态、能力亮起和爆发后三种状态，确认角色轮廓、眼神和关键手部仍可读。

2D交付俯视布局、透视设定、前中后景层、互动道具及破坏替换图。3D交付尺度、模块、材质、碰撞/接触代理和破坏变体规格；多边形与贴图预算依目标平台和景别决定，不给所有项目统一数值。AI制作交付稳定场景锚点、主要角度参考和状态说明，不能假设一次文字描述会自动保持所有角度一致。

## 画风不是一串形容词

建立一张风格卡：

`人物比例｜轮廓与线条｜面部简化程度｜材质与纹理｜明暗分区｜光源逻辑｜色彩层级｜透视与构图｜动作变形幅度｜特效绘制语言｜背景细节密度`

选择一套主语言，其余作为局部手段。下列是可选方向，不是类型规定：

| 方向 | 人物与场景 | 动作与特效适配 |
|---|---|---|
| 清晰赛璐璐 | 形体概括、有限明暗层、可控边线 | 强关键姿态、局部速度线、块面冲击；避免无意转为写实烟火 |
| 半写实3D | 体积、材质与光源关系较完整 | 重心与次级运动清晰，局部粒子与体积效应保留轮廓 |
| 水墨/平面装饰 | 留白、笔触、平面构成有统一规则 | 墨势可替代拖尾，破墨可承担撞击；仍保留目标与局势线索 |
| 夸张喜剧 | 比例和变形弹性较大 | 延迟反应、压扁拉长、图形化冲击；恢复遵守本片喜剧规则 |
| 图形化科幻 | 结构分区、信号与机械形状清楚 | 充能状态、失效模式、射线边界可读；界面文字不盖住交手 |

角色能力可以不同，但线条粗细、阴影处理、颗粒尺度与合成习惯应像同一作品。强者不必更亮，邪恶角色不必黑紫色。通过形状、姿态、运动和材料反应同时区分阵营，避免只靠颜色。

## 国漫视觉母题与场景锚点图

母题库是本项目的可选视觉语汇，不是把所有中国风元素堆进一镜：

| 母题方向 | 可转成的视觉/动作语言 | 选择与考据边界 |
|---|---|---|
| 笔势、留白、墨色层次 | 连招方向、蓄势留白、余波边缘 | 笔触与实体力分清，不以水墨自动证明传统真实性 |
| 山石、云水、地势 | 身法路线、远近尺度、环境呼吸 | 使用具体地貌与材质逻辑，避免背景符号化重复 |
| 梁柱、门阙、院落空间 | 封路、借柱、门内外人物关系 | 建筑形制与受力依原型核对，不让装饰件承担全部结构 |
| 织物、甲片、金属器表 | 身份轮廓、动作拖曳、材质触感 | 年代、工艺、纹样适用性查来源，不随机贴龙凤纹 |
| 几何纹样、器物结构、仪式秩序 | 法术构件、节律、阵列与空间构成 | 具体宗教/礼制含义另核实，原创能力不伪称历史术法 |

每个项目选少量主母题，登记`母题ID｜文化/材料原型与来源｜造型规则｜动作/能力/场景中的用途｜不借用项`。角色、场景和特效共享规则，但不要求每一层复制同一花纹。具体事实按 [文化考据](cultural-research.md) 核实。

场景锚点图至少包括俯视布局与本场主要摄影角度，标出左右端点、中部、前后层、高差、出口、交互点和角色尺度。给锚点稳定ID，如门柱P01、断梁B02；状态图用完好/穿孔/残架等版本对应。图中标摄影机侧、行进路线、横移可覆盖范围与不可穿透区，横向延展时保持锚点顺序和透视关系。

生成段引用具体角度与状态版本；墙面细密重复纹理可降密度，不能依赖重复瓦纹充当唯一定位。接触、坠落与破坏段优先制作同视角首尾锚点，不假设AI能从一张全景自动恢复全部空间。

## 横屏灯光与观看尺寸

暗场保留关键轮廓和局部明暗差，不简单全局提亮。爆发光若会照亮人物，就在附着面和邻近环境留下相应变化；若采用平面抽象效果，可明确其不参与写实照明。雨雾、背景纹理和装饰线不抢走动作焦点。

横屏用左右分区与前后层次呈现多方关系；关键接触在中心动作安全区可读，边缘少承载唯一信息。桌面与手机竖持预览分别检查全身轮廓、持械手和敌我识别，小画面读不出的关键机制补中近景，字幕避开动作区；规格字段见 [画幅与合规](framing-and-compliance.md)。

跨画幅必须重新布局并验收，不能只靠裁切迁移。

## 风格签名补充

在原画风卡中增记“风格签名”：经用户确认的3—5个不可替代特征，逐段继承；它们是固定描述，不新增事件条数。其余色彩/构图/光线细化按需见[色彩](../visual/color-system.md)、[构图](../visual/composition.md)、[光线](../visual/lighting.md)，不另立重复美学阈值。

转写示例：卡片“红叶主色、灰黑人物、中轴树列、冷侧光”→“3D写实国漫，黑发灰衣剑客持直剑。暗红叶面铺满林间小径，笔直树列向薄雾延伸，左侧冷光擦亮握剑的手。”这些是可替换形式示例，不替用户默认选红林。分工：本文件建造空间和固定画风；[风格转译](../visual/style-translation.md)负责从参考提取签名。
