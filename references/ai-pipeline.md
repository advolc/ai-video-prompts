# AI制作管线、失败诊断与阶段验收

## 阶段产物

| 阶段 | 交接产物 | 进入下一阶段的条件 |
|---|---|---|
| 需求锁定 | 项目卡、横屏规格、单集变化、预算、素材权限台账 | 不混画幅，目标与限制明确 |
| 美术与考据 | 角色一致性卡、场景锚点图、兵器/术法卡、来源记录 | 已选有图或无图流程；有图核实角度/结构，无图明确可见描述与复现待验项 |
| 武指与分镜 | 空间图、动作节拍、镜头时间表、低成本预演 | 攻防路径、有效距离、发力与后果成立 |
| 生成规划 | 实际使用条件、SHOT—GEN—CLIP映射、起止状态、生成正文、控制栏、独立制作备注 | 完成生成交接检查；净长正确，逐段负荷已处理，关键动作有通过/失败条件；模板额外核对3+2、壳例分离与平台退路 |
| 小样验证 | 代表性接触段、横移段或多人段、实际输出评估 | 工具可在当前复杂度下实现主要要求 |
| 批量与筛选 | 原始输出、版本/参数、通过/失败标签、选用区间 | 不将失败尾帧继续当批准基准 |
| 局部返工与剪辑 | 修复段、接缝、连续状态、画幅/调色一致 | 完整播放可读，空间和节奏成立 |
| 声音与口型 | 分轨、事件表、对白时间与口型检查 | 实际试听并核对同步、遮蔽、角色音色 |
| 后期制作 | 调色/合成/字幕/音频工程及返工版本 | 动作不被遮盖，视觉统一，字幕和声音已按实际条件检查 |
| 输出交付 | 母版、目标交付版、字幕分轨、依赖清单 | 文件解码/播放/实际听音分别记录，不冒充已发布 |
| 成片与交接 | 母版、字幕、所需分轨、资产/权限记录与验收说明 | 桌面和手机竖持小画面均检查过 |

只交策划时将执行阶段标“待执行”，不制造已跑过模型的表述。模型名、版本、首尾帧/参考能力、单段时长和当前规则先按工具实际界面或官方资料确认。没有平台信息时交平台无关方案与试验假设。

平台退路必须对应实际缺失能力。采用模板时见[结构契约](template-contract.md)：文本描述不能冒充图像身份锁定，后期选帧不能冒充尾帧控制；精细术法或关键动作的降级如改变固定设定，先取得选择。原生音频未确认时转制作备注保留任务，不据此断言平台没有音频能力。

## 关键动作先定义怎样算通过

每个决定局势的事件记录：`事件ID｜施力者/接触或支撑面｜起止姿态与方向｜关键先后关系｜可见结果｜拒收现象`。按事件选少量必要指标，不强迫所有镜头填相同数量。检查实际连续画面，抽帧用于定位与加密；精确时序不凭单帧推断。

| 示例事件 | 必须可见的关系 | 应判返工的偏差 |
|---|---|---|
| 斜下锤拳破防 | 拳路自上向下接上护臂；防守受压后身体向既定落点失衡 | 换成胸前平推拳、尚未接触就自行飞走、只有碎光而无受力方向 |
| 双靴落瓦滑退 | 双脚先触瓦，屈膝承重；若设定为蹲姿则臀部离瓦，滑退方向连续 | 换成坐姿滑行、支撑点漂离屋面、脚未承重而先出现长滑痕 |
| 剑刃压花瓣 | 刃与指定花瓣先交汇，再形变/释放；结果交代双方位置与地形变化 | 接触前爆炸、接触藏在全程强光里、六瓣构件或受力连接在关键处不可辨 |

这些是对应动作意图的例子，不把低蹲、六瓣或屋顶设为所有打戏规范。关键项不通过即标返工/未实现；不能以总分、清晰脸或华丽特效抵消。若该段确需不同动作结果，先记录为设计变更，不悄悄降低验收后称原要求完成。

## 失败诊断树

先按[对话规则](../ux/conversation-rules.md)接住挫败，再只取定位最早错误所需信息；用户说停止则停，不继续要样本。不是先给用户一张长清单。

从最早失败的层开始，每轮只改主要变量，保留对照结果：

先比对实际提交的文本、请求时长、参考输入与本次文件覆盖范围，不只读原始分镜。区分设计因果错误、规则已有但稿件未执行、用户实际生成条件改变、模型执行偏差与剪辑问题；可同时存在，单次输出不推断各方责任百分比或模型硬上限。

1. 人/物身份先错？先核实实际是否上传参考；有图查职责、版本、角度与镜像，无图查文字可区分性及身份要求是否超出已验证范围；不将缺图归因于参考失效。
2. 身份正确但位置跳？检查世界/屏幕左右、轴线、场景锚点、首尾状态和损毁版本；用地图与稳定镜头恢复关系。
3. 空间正确但攻击无效？检查距离、握法、重心、攻击面和应对；简化交锋或用可控预演，负面词不能补武指。
4. 动作成立但接触怪？检查碰撞时点、肢体遮挡、手柄与武器结构；移开分段接缝、缩小交互数量或另做接触镜头。
5. 接触成立但没力度？检查位移/卸力、恢复、材料响应及声音同步，依 [打击感](hit-feel.md) 逐层补，不先扩大爆光。
6. 只在横移/边缘失败？检查端点锚点与纹理重复，减少边缘角色和摄影幅度，改稳定机位或可控背景。
7. 单段都好但拼不起来？核对姿态、动量、光影、镜头速度和声音尾段；匹配失败就改明确切镜，不强做叠化。
8. 画面成立但台词/口型错？以实际音频时间重排对白或局部口型，别为一句话破坏全段动作。
9. 桌面好、手机看不清？重排接触景别、主体/字幕区和边缘信息，不只提高导出分辨率。

## 可执行的对照小样

不自动付费运行。用户已授权试片时，在预算内选最早失败的一个事件；仅交策划时交下列试验计划并标未执行。记录：`样本ID｜模型/设置/实际参考｜唯一主要改动｜原稿/实际输入｜输出｜事件验收结果｜结论及不确定项`。

1. 保留原样本作基线。先只减少独立攻防事件，尽量保留人物、风格、机位、请求时长及其余设置，查看目标事件是否更完整；不要同时换模型、加参考和大幅改机位。
2. 若仍失败，沿用简化稿，只将摄影改为稳定机位，检查接触和支撑；下一轮再单独尝试明确的起始姿态文字或实际姿态参考。缺图时提供文字分支，不强迫补图。
3. 若需缩短请求时长，把它作为另一个变量，按真实界面操作；用户坚持一次长段时，只测试该方式内的取舍，不擅自改成分段方案。
4. 只有确需比较工具且用户授权时，保持尽量等价的输入与设置换模型；工具无法匹配的条件列出来。单个成功或失败是样本，不报告为成功率或能力上限；没有固定随机条件时仍有抽样噪声。

简化后改善，支持任务组织是本次瓶颈之一；仍失败，只能说明在这些已测条件下未实现。预算内重复同类失败且无新变量可试，就换镜头设计、可控预演/合成或报告未实现，不继续堆词。

## 预算与停止条件

项目开始约定小样成本、单段尝试上限和整体预算。缺预算时先交方案，不自动批量付费生成。用户已授权的范围内先试最高风险段，再扩批；每次失败记录原因与改动。同类失败反复出现且没有新改法，切换分镜、段长、可控动画/合成或交付可审看的替代方案，不无限抽卡。

小样后再扩批是实际生成的预算策略，不是文字交付锁。用户要全量提示词时，按[生成交接](generation-handoff.md)一次交齐所有拆分单元和接缝；只有用户选择分批拿文字时才先交一段等反馈。从[灵感孵化](inspiration-wizard.md)进入的分批试片失败，优先保留用户已定五槽，核对实际输出/输入/设置后局部诊断；确需改变已定设定时先问联动范围，不机械重启整套向导。

完成报告分别列：设计完成、资产已产出、生成已跑、动态预演已看、音轨已听、手机观看已验、平台要求已核。结构/链接/时长检查通过只覆盖文档可靠性，不等于模型成功率、无缝长镜头或发布合规已经验证。

## 跨层验收补充

以下是内部或用户主动评审时使用，日常不自动打分：

- [ ] 视觉：主色/构图/光向/材质关系成立，关键接触可读；以实际视频检查而非只看封面。
- [ ] 叙事：观众能辨目标与变化，信息先后、反应时间和情绪留白有依据。
- [ ] 声音：实际听过环境/拟音/音乐层次、同步和静默；未听不勾选。

后期路径见[工具链](../production/toolchain.md)，导出检查见[输出规格](../post/output-specs.md)。原动作验收与否决条件继续有效，不用整体评分抵消关键失败。
