# 摄影、节奏与声音

每镜交代一个主要信息。电影感来自对可见关系的清楚表述，不靠“史诗”“大片”“疯狂运镜”等形容词。

## 1. 每镜一条主信息

先写观众此刻需知道什么，再选景别和运动。全身动作、接触细节、人物判断、局势结果是不同任务。一镜可兼次要任务，但不能又高速环绕、变焦、翻滚，又遮住主要接触。

| 方法 | 适合用途 | 执行限制 |
|---|---|---|
| 稳定全景/中远景 | 起始距离、连续交锋、能力差距 | 不把人物缩成点；轮廓与背景有对比 |
| 跟拍/平行跟随 | 追逐、进退、横向移动 | 背景锚点显示运动；给下一威胁留空间 |
| 推进/后移 | 进入心理压力、揭示结果 | 相机移动改变透视，不能与纯变焦混淆 |
| 摇摄/甩镜 | 转移注意、突袭 | 落点须可辨；模糊不能遮掉全部关键动作 |
| 短弧线/环绕 | 侧绕、攻防交换、夺取控制 | 地形与轴线可读；绕过后重记画面左右 |
| 低/高机位 | 重量、压迫、高差、路线 | 角度本身不代表强，须结合动作和构图 |
| 接触特写 | 决定性抓握、接取、断裂、破防 | 须接回身体，不能多出不存在的手 |
| 视线/主观镜头 | 识别威胁、误判、锁定目标 | 给出所看对象；有意失稳表现眩晕后须重建方位 |
| 远景/俯拍 | 尺度、群体关系、落点、损毁 | 切回近景时保持方向和高度 |
| 固定镜头、人物出画 | 突然提速、余波、悬念 | 随后展示必要结果，不能靠画外逃避设计动作 |

焦距未经验证时，描述广角感、正常透视或压缩感。三维（3D）相机参数须说明传感器/画幅条件，并标为预演建议。成片无法反推出精确毫米焦距。

## 2. 跨镜连续性

记录首尾构图、画面站位、视线目标、运动方向、出入画边缘。通常保持轴线同侧。有意越轴可用连续运动、无明显方向的中性镜头，或清楚的新全景重建方位。大混战可重定义局部轴线，不用一条线解释全场。把当前/逼近/侧绕/封路威胁映射到画面左右与景深分区（见 `action-causality.md` 第9节），人物穿越或摄影换侧后更新。

切点可落在起手、接触、反应、落地，效果各不同。先见危险再见反应制造紧张；先受惊再揭示制造意外。不要总切“眼、拳、闪光”。关键攻击仍须跨切点连通路径与结果。极短动作阶段的短暂重复可强调冲击，但不能让人物无缘由倒回。有意迷向可适配眩晕或恐惧，之后重建空间。这是设计选择，不是连续性缺陷的补丁。

## 3. 四种独立时间

1. **动作时间：** 预备、加速、交汇、恢复、结果。
2. **摄影时间：** 相机何时起动、跟随、超过主体、落稳。
3. **剪辑时间：** 何时换镜，信息是否已读清。
4. **动画时间：** 关键姿态间隔、停留、中间帧密度。输出帧率不等于每秒独立姿态数；30fps文件不代表每个部位每秒都更新30次。

速度可来自更长的连续交锋，慢感可来自观察与未解除的威胁。爆发前后静默、姿态幅度、空间变化，往往比多切镜有效。

## 4. 节奏

先写信息节拍（“试探、识破、转折、局部失败、借地形脱身”），再分秒数。也可开场即高潮、全程施压、喜剧停顿，不强制一条曲线。对峙停顿须有信息变化：重心移动、注意转移、出口缩小、作出决定。慢动作强调难读瞬间或主观体验，定格可作风格重音，但都不默认使用。快交锋后给冲击、呼吸、目标进展或新距离，让峰值兑现。

同时检查镜长与动作能否在时限内完成。24fps下2帧强调约0.083秒，只是起步测试；其他帧率重算。“三帧震动”不是通用标准。跨镜同时发生的动作共用一条时间线，不重复计时。低精度预演至少完整播放一次；静态分镜不证明节奏有效。

## 5. 把提示词写成镜头表

先填可检查字段，再压成简短段落。

| 字段 | 填写内容 | 检查 |
|---|---|---|
| 位置/高度 | 低机位、平视、过肩、柱后；地面参照和建议高度 | 匹配首帧与指定主体；高度是设计目标，不是精确保证 |
| 构图 | 左右、前后、画幅占比、是否见脚或地砖、接触安全区 | 关键身体和兵器有空间；特写能接回全身 |
| 运动 | 推/拉/摇/横移选一种：方向、锚点、行程、起止 | 视差匹配运动；“快”不能代替路径 |
| 主动作 | 谁从何处起动、攻击线、谁应对、一个主要接触及结果 | 手、刃、目标、支撑对齐；终点可作为下一段种子 |
| 灯光 | 主光方向与软硬、保留阴影、能力补光；雨雾仅在已定时用 | 光向、地面状态、相邻片段一致；轮廓不被吞没 |
| 时间 | 净长、关键事件窗口、请求余量、剪辑区间 | 时长匹配动作量；余量不计入剧情 |

示意镜头表：16:9，净长4秒；相机在通道南侧，建议离地0.6米、略仰，中远景保留双方双脚，地面占下三分之一；A左B右。B上步向左挺枪，A右手用短杖把枪往北架偏，只有一次杆部接触。接触后A向左退半步，B收枪。相机向左摇约半步，在接触前减速，接触期间稳住；门柱保持在左后。右上冷光让阴影中的衣褶可见；不加天气、不做大闪光。结尾兵器仍在原手。

高度、地面占比、运动距离，须通过首帧或预演构图相互一致。不能给工具互相矛盾的数字。人物身份、衣物、兵器比例来自获批参考。

## 6. 按动机选景别，不按习惯（防“监控式覆盖”）

- **拒绝平铺。** 普通对白先用中景或双人镜头建立关系和站位，但不等于跳过日常动作。心理转折、发现、出鞘，或必须看清的接触才用特写。特写是视觉重音，须带新信息；不每句切脸，更不能静默删用户指定表情或物件特写。
- **过肩与遮挡。** 过肩保留对方肩线；已有门框、柱子、碎发可加前景层次。遮挡不能盖住当下关键视线、手、接触。机位须接回双人空间。不能为“电影感”新加前景物。
- **动势匹配转场。** 两镜已有相似动作（前镜举杯、后镜举刀）时可匹配剪辑。这是两镜间剪辑连接，不是一镜内杯子变刀，也不为匹配强加兵器。声音桥让下一场已有声音提前进入当前画面，归剪辑/音频处理。

每段仍只有一个主要摄影任务。匹配剪辑、声音桥、变速和剪辑执行属于管理层，不能伪装成平台控件或新打斗。

**主观摄影。** 状态驱动的镜头选择（眩晕式手持轻晃、收窄或压缩的透视、真实镜头上的介质）是当前片段的基本情境选项，不强制加载深层心理或台词系统；模糊和污迹不能遮失败动作。

**高潮复杂运镜。** 绑定动作锚点：谁的哪个动作阶段启动，哪个可定位部位或接触点持续在画内，哪种可见状态结束。路径不可行或平台控制未核实时，保留观看目标与关键交汇可读，舍弃扭曲的空间过渡。不能把不同时间或空间的摄影任务藏成装饰短语。

运镜公式：**当前空间物理限制＋人物发力路径与位移＋此刻情绪张力＝本段镜头语言。** 先查可用观察路径、遮挡、支撑、关键交汇、必须看清的信息，再决定相机在哪、距离多远、朝哪、关注什么。用自然语言写可见关系，不把后台摄影术语当指令粘贴，不每场套同种运镜。适合固定观察的片段不强加运动。

## 7. 声音

三个层面：画面展示什么，声音补充什么，什么留后期。

| 层 | 功能 | 候选（含无对白打斗） |
|---|---|---|
| 环境声 | 地点、尺度、连续性 | 雨打瓦、远风；跨镜保持同一空间 |
| 拟音 | 动作材质与重量 | 鞋底承重、布料回落、短金属鸣；接触音只在接触时响 |
| 音乐 | 关系与节奏 | 接触前降低，结果后重入；主题不遮关键声音 |
| 静默 | 突出决定或余波 | 决定前短撤音乐和次要声；是否留空间底噪依意图 |

声画同步让事件可读。对位（平静音乐配紧张画面）可以，但不破坏必要因果。声音桥使用下一场画外声音，须有方向和空间依据。音乐驱动作品先标主拍与段落，再决定哪些动作对齐；变奏改配器、节奏、音区，不必每场新主题。

声音不复述画面：刀停住时，声音仍可表现受压金属；台词不旁白画面结果已说明的事。

打击音（接触瞬间）也从 `action-causality.md` 第5节接触链推导。分轨：对白/呼吸、发力与破风、接触起音、身体或机械反应、材质破裂、环境底、音乐、尾音。绑定事件ID，不永久烘焙合轨。切镜后尾音与环境继续，按空间调音量和方向。不同材质与结果用不同层，不每拳同一低频爆响。先规划听觉前后层次，为对白、关键起音、低频留位。最终通过试听判断削波、掩蔽、同步、疲劳。响度和交付分轨依当前发行要求，不编平台数值。波形或电平不能代替试听。临时静音是诊断手段，不代表可以省声音。

**主观心理声学。** 根据已定冲击、人物体力、注意力、叙事视角，判断是否需要一次主观声音变化。不套“受击→耳鸣”“恐惧→心跳”。轻触、疲劳、重击不共用一套；客观旁观镜不默认进入受击者听觉。条件适合可选短高频鸣、环境后退、心跳强调、短暂听觉变钝，只取一项有本场信息的处理，给进入、恢复与原空间的连续性。不能从音效推断新耳聋或脑伤，不能把主观处理当新身体损伤，也不能无匹配力度就强耳鸣。

极端恐惧或杀招前，评估“抽真空”式心理静默：减少次要音乐和环境，只留一个已有微声（袖擦、呼吸）。取决于人物注意和已定节奏，不每击都静音，不移除读清关键接触所需声音。这是主观混音，不是场内物理空气改变。

生理声音服从体力与已定发力、受击时机（见 `action-causality.md`）。精细耳鸣滤波、响度曲线、静默打击点归音频后期。平台原生音频已核实且用户选用时，简单环境与接触音可进入生成正文（“掌根落下时一声闷响”）；否则留制作方案。不把复杂混音术语塞视频模型，也不为声音逼用户换平台。最终提示词不含模块解释。不能只凭声音方案或波形就称“已试听通过”。
