# 题材混搭


先定主体验和一个次元素，再谈比例；“武侠为主、科幻提供能力代价”比僵硬百分比更可执行。比例若使用仅作设计估计，不是验收分数。世界规则、材质和台词需同源，冲突由[裁决](../core/precedence-rules.md)处理，不自动换用户主设定。

| 组合 | 统一支点 | 容易失效的地方 |
|---|---|---|
| 武侠+科幻 | 身法受机械负荷约束，器物形制保持一套逻辑 | 古语与工程口号随机轮换；科技无限解围 |
| 恐怖+喜剧 | 同一误判先带危险再产生笑点 | 笑点消除后果，恐怖毫无压力 |
| 爱情+悬疑 | 亲密关系决定谁可信与信息可见范围 | 用隐瞒全部信息冒充悬疑 |
| 黑色+奇幻 | 超常能力也有交易代价和人际后果 | 魔法抹平已建立的道德选择 |

流程：保留主类型的核心承诺→选择次元素进入哪个可见机制→列不可兼容点→给一个融合或分离候选→先做最小场景。失败症状是光色、台词、物理规则分别来自不同片，角色像贴图；先减次元素，不靠更多风格词粘合。混搭卡是启发，不是自动套用；所有动作仍共用3+2。
