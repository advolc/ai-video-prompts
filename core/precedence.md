# Precedence

The ladder is in `SKILL.md`. This page only gives resolution examples. It claims no authority beyond that ladder.

Preserve the user's explicit effect and locked implementation details. Adjust unspecified staging within the user's authorization; ask only when resolving a real conflict would change a locked hand, timing, action, outcome or world rule. Present concrete alternatives together. Do not silently delete a requested gesture, close-up or action, and do not claim incompatible simultaneous demands have been solved merely by writing both. Continue independent work while a consequential choice is pending.

| Conflict | Resolution |
|---|---|
| The user wants a gesture during a contact exchange; the gesture needs the same hand | Preserve the gesture's intended effect. Use a free hand or a natural opening only if hand/timing were not locked. If the same hand and simultaneity are explicit, explain the conflict and offer a release/regrip, a different beat, or an authorized world-rule solution; wait for the affected choice |
| Rich skin detail vs a wide shot where pores cannot read | Lens validity: keep identity anchors, drop pore-level language, move texture to what the shot size can show (shine, flush, hair, fabric) |
| User's explicit face close-up vs a fast fight | Preserve the close-up and requested fight intensity. Design framing or coverage within authorized staging; if a solution would change locked timing, continuous-take intent or action, offer concrete alternatives and wait for that choice |
| The user says the character flies, hovers or changes direction in mid-air | Apply the declared world's mechanics, including a newly authorized ability. Do not impose realistic gravity on an explicit supernatural premise. Clarify only if this contradicts an already locked rule; preserve coherent triggers/results without inventing extra powers, costs or plot |
| A prop that would add texture vs a locked "no extra objects" instruction | Locked wins; use posture and light instead |
| The model's prompt limit vs Extended length | Fit the largest version that fits; say so in one line; never cut Tier A or identity |
| Two style references that disagree | The user's stated priority; else the primary style carries optics and light, the secondary contributes one dimension |
| Dialogue length vs clip duration | Split by conversation unit or lengthen the clip request; do not silently trim lines |
