# Precedence

The ladder is in `SKILL.md`. This page only gives resolution examples. It claims no authority beyond that ladder.

| Conflict | Resolution |
|---|---|
| The user wants a gesture during a contact exchange; the gesture needs the same hand | Tier A wins; move the gesture to the free hand or a pause after the exchange |
| Rich skin detail vs a wide shot where pores cannot read | Lens validity: keep identity anchors, drop pore-level language, move texture to what the shot size can show (shine, flush, hair, fabric) |
| User's explicit face close-up vs a fast fight | User's decision wins; offer options (separate reaction shot, low-motion close-up, test the long take) and wait |
| A prop that would add texture vs a locked "no extra objects" instruction | Locked wins; use posture and light instead |
| The model's prompt limit vs Extended length | Fit the largest version that fits; say so in one line; never cut Tier A or identity |
| Two style references that disagree | The user's stated priority; else the primary style carries optics and light, the secondary contributes one dimension |
| Dialogue length vs clip duration | Split by conversation unit or lengthen the clip request; do not silently trim lines |
