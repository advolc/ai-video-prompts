# Reference index

Use only to resolve a task-specific gap after the primary route. Entries indicate responsibility, not an instruction to read every matching row. Paths below are package-root-relative.

## Expansion triggers

Select relevant sections for the unresolved design responsibility. Consider the five Lens dimensions; read and apply only those relevant to the shot, style or observed problem. A dimension may need no new detail. Do not load unrelated reference libraries.

| Task has... | Read |
|---|---|
| Pipeline or prose questions unresolved after the primary route | `core/pipeline.md`, `core/context-routing.md`, `lens/lens-layer.md`, `lens/output-skeletons.md` |
| Relevant look/performance detail or a diagnosed gap: select the needed pass | `lens/optics-and-stock.md`, `lens/physical-light.md`, `lens/skin-and-material.md`, `lens/face-pass.md`, `lens/body-and-status.md` |
| Any spoken line, monologue, negotiation, confrontation | `dialogue/situation-profiles.md`, `dialogue/spatial-blocking.md`, `dialogue/spoken-register.md`, `dialogue/conversation-units.md`, then `references/dialogue-engine.md` (cards: `references/dialogue-reference-cards.md`) |
| Fight, chase, weapons, multi-clip action | `references/action-modes.md`, `references/spatial-tactics.md`, `references/choreography.md`, `references/hit-feel.md`, `references/action-reference-system.md`, `references/consistency.md` |
| Silent interaction between co-present characters | `dialogue/situation-profiles.md`, `dialogue/spatial-blocking.md` |
| An emotional or psychological beat, close-up, concealment | `references/performance-and-psychology.md`, `references/character-and-performance.md` |
| Camera, rhythm, composition, color | `references/camera-and-rhythm.md`, `visual/composition-and-color.md` |
| Setting, props, environment, weather | `references/world-and-style.md`, `visual/environment-interaction.md`, `narrative/story-and-scene.md` |
| Powers, VFX | `references/powers-and-vfx.md` |
| A style or reference | `visual/style-translation.md`, `visual/style-library.md` |
| Sound or voice | `sound/sound-and-voice.md`, `references/hit-feel.md` |
| Splitting into clips, continuity, platform | `references/prompts-and-segments.md`, `references/generation-handoff.md`, `models/README.md` |
| Review an actual generated video; measurements or contact sheet | [Analyzer usage](../scripts/analyze_clip.md), `scripts/analyze_clip.py`, `references/delivery-and-qa.md` (measurements supplement direct viewing; sound requires listening) |
| Detailed delivery review beyond the primary semantic check | `references/delivery-and-qa.md` |
| Story ideation from nothing | `references/inspiration-wizard.md`, `references/inspiration-library.md` |
| Real periods, objects, sources; compliance | `references/cultural-research.md`, `references/source-scope.md`, `references/framing-and-compliance.md` |
| Planning and tooling a full pipeline | `references/ai-pipeline.md`, `references/template-contract.md` (optional expanded production ledgers; required spatial records remain in force), `references/delivery-and-example.md` (production design example) |
| Workflow, planning, post, release | `production/workflow.md`, `post/finishing-and-release.md`, `quality/quality.md` |
| Tone and interaction rules | `ux/interaction.md` |
