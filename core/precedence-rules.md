# 冲突裁决


先守总不变量：3+2、六项接缝、三层分离、防偷懒与默认纯文本不因新模块扩展而变更。用户明确要工程表属于既有交付例外。系统/开发者安全权限高于本技能内部表；用户偏好不能授权越权或改变平台硬上限。

内部七级依次为：①用户明确偏好与已定事实；②安全/合规/平台硬约束；③叙事目标与角色一致性；④动作因果与接触可读性；⑤构图/色彩/光线/风格；⑥氛围/情绪；⑦工程便利与生成成功率。①与②真实冲突时保留意图并调整实现方式，不伪称偏好突破硬约束。仅把取舍翻成人话，不展示本表。

| 冲突 | 裁决与理由 |
|---|---|
| 一镜一主信息 / 静止长镜承情绪 | 主信息可以是一次等待中关系改变；有可见变化即可静止，不为了动而加切镜 |
| 对称构图 / 动作越轴 | 接触与左右可读优先；用正面中性镜或连续移动重建，再恢复对称，不以对称遮错位 |
| 单色统治 / 平台色漂 | 主色意图保留；用参考、简化材质、后期统一实现，不能承诺文字绝对锁色 |
| 文戏微相 / 生成稳定 | 用户明确的面部目标不得静默删；给独立反应镜或肢体代理供选，微相仍共用3+2额度 |
| 默认纯文本 / 要工程表 | 仅在主动索要时展示图纸；默认稿直接给白话，不能自动双版 |
| 角色完整锚点 / 短提示词 | 优先2—3个区分锚点与武器，保留关键伤损，少写装饰，不丢身份 |
| 评分建议 / 日常协作 | 日常不评分；用户明确评审才给判断，编辑角色可直接指出所求问题 |
| 向导每轮快照 / 不打断微调 | 向导探索继续短快照；退出向导后每3—4轮或转向才总结，不把卡当用户作业 |
| “不做了” / 给下一步 | 先停止执行；可留一句以后再接，不追加任务、诊断或诱导继续 |
| 视觉构图 / 运镜节奏；单句台词 / 对话调度 | 前者分别管画面内关系、单句意图；后者管时间变化、场景组织。约束落同一镜头，不重复叠加 |
| 实时反馈 / 项目级反馈 | 先局部修改，再按需记项目台账；不让记录阻塞创作 |

所有新增输出建议服从[对话规则](../ux/conversation-rules.md)；最终提示词交付服从[防偷懒协议](../references/anti-lazy-and-delivery.md)。证据不足必须如实说明，不把隐藏状态解释为隐藏会影响决策的限制。

## 情境细节升级的冲突处理

静默基础推演优先于旧“先询问质感”的一般输出建议，但仅限既定事实的细化，不取消创意就绪、深度台词/心理系统及全面造型/陈设代拟的边界。固定纹理/风向/光源不计动作，原接触结果写在原因果链中，非关键可忽略信号共用2条氛围；滑倒、失明、取物、破墙等新事件不得免费追加。生活与道具系统共享整场一次小动作，不各算一份。
原生音频是否支持仍按实际使用条件，复杂耳鸣/静默曲线与顿帧仍分流管理层。默认生成正文不解释过程；如方案要改用户明确目标，仍不能靠静默隐藏改动。路径上，references/camera-and-rhythm.md是基础运镜，production/camera-and-rhythm.md仅补主观情绪镜语，id不同、互相链接，不维护重复轴线规则。
