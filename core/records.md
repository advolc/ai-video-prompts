# Shared project records

## Selection

Design checks are required when relevant; expanded forms are optional. Keep shared facts once per scene/version: goal, locked facts and provenance, references/input mode, characters and current state, spatial opening/end, quality targets, unresolved decisions. Cards reference this scene/version rather than re-copying it. Update changed fields and dependent states only.

| View | Use when | Skip when | Shared facts and extension |
|---|---|---|---|
| [Continuation card](../assets/templates/continuation-state-card.md) | Another segment/session needs explicit state or several branches remain active | A standalone draft with no handoff | Shared facts + branch, end state, next task |
| [Dialogue card](../assets/templates/dialogue-design-card.md) | Several turns/speakers or a difficult subtext need an expanded design | A simple line/reaction is clear in a short record | Shared facts + language, intention, turns and listener responses |
| [Performance card](../assets/templates/performance-design-card.md) | A difficult concealment or emotional transition needs detailed staging | The action already fully conveys it | Shared facts + stimulus, psychological action, visible development |
| [Production notes](../assets/templates/production-notes.md) | Actual generation, versions, selection and post-production are being managed | Prompt-only task without production management | Shared facts + settings, outputs, tests and handoff |

Do not ask the user to fill these forms or print them by default. One scene can use several views without duplicating shared state. A short internal sentence can satisfy the necessary design record; complex cases receive the detail they need. Card completeness is not creative quality.
