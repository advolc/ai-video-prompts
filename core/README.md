# 维护与执行入口


先看任务路由确定要做什么，再看冲突裁决，加载图限制本轮内容，模块契约约束增量文件。四件套分别是[路由](task-router.md)、[契约](module-contract.md)、[加载图](load-graph.md)、[裁决](precedence-rules.md)。维护时先读契约与裁决，再改目标模块，不借扩展改核心导出格式。

规则不可见铁律：模块名、规则编号、加载图、裁决表、验收清单和内部待核标记默认不作为创作回复展示；用户主动索要时才展开。README 本身是主动阅读的说明，不限制仓库文档正常列出模块。真实限制用人话交代，不能隐藏证据缺口。对外交互统一入口：[对话规则](../ux/conversation-rules.md)。
