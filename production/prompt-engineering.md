# 提示词工程与平台语法


自然语言为最终默认：短首句交代画风和身份，随后场景机位与连贯因果。结构化字段用于内部设计或用户主动看图纸；两者不能混在复制区。权重、括号、冒号、多提示混合、参考标记和negative字段均是平台/模型/模式特定语法，没有通用`(词:1.4)`规则。

先核实实际模式是否支持语法；不支持或不清楚就用简洁肯定句。强调靠明确主体、接触和顺序，不反复堆“必须”。混合提示先指定主语言与可变维度，不把矛盾风格平均粘合。分段遵守事件负荷与状态，不能写时间戳就假设平台按秒执行。

负面约束按画风/空间/动作/材质分层只选当前高风险1—2项，内部仍最多2条针对性禁止；最终正文转正向可见关系，确认支持的独立负面栏才另给。详见[负面词](negative-prompts.md)。参考图已有外观时精简重复但仍保本技能自足锚点，不把“同上”交用户拼。

语义翻译冻结事实：谁、武器、先后、方向、结果、主运镜。专业名词如发力链、心理动作、Laban质感要翻成支撑、身体位置与可见节奏。每次只改一主要变量，以实际输出判断；词数不是质量指标。最后走[生成交接](../references/generation-handoff.md)，不以规则符合替代平台试片。
