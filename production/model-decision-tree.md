# 模型与工作方式决策树


这是工作方式选择，不给平台打泛化能力分；每个节点先核当前模式可用性，示意图和预演不是模型执行保证。

| 首要需求 | 候选路径 | 失败退路 |
|---|---|---|
| 角色一致性 | 有合格参考→图生视频/角色参考；没图先文字可辨身份或做资产 | 参考角度/服饰不符先修资产，避免多图相互冲突 |
| 复杂动作/接触 | 减并发、分事件；支持时用首尾姿态或可控动作参考 | 拆接触阶段、固定机位、白模或合成；不强行要求有尾帧 |
| 风格探索 | 文生视频或先文生图比较签名 | 固定场景，只改一维，选定后再锁角色 |
| 连贯长镜 | 先定连续空间，再视支持选首尾帧/分段承接 | 首尾帧不能保证中间路径；插帧只补采样，不能补新剧情或复杂接触 |
| 精确口型 | 专用口型流程、合格音轨与近景 | 拆独立对白镜，或画外音；不在打斗同段硬塞精确微相 |
| 纯氛围 | 文生视频、稳定机位、一个可见变化 | 减细节、改静图轻运动或后期，不靠空镜凑时长 |

顺序：用户目标→现有素材→界面能力→成本约束→小样结果。一个品牌不同版本/接入平台能力可不同；未知写内部待核，对用户说“先按你当前能选的设置来”。一旦改变用户明确目标，先给选择，不静默以稳定性名义降级。能力信息见[平台矩阵](../distribution/platform-matrix.md)。
