# AI生成视频提示词 Skill

> 👉 **不想看代码？** 把仓库完整下载保存，再把 `SKILL.md` 和本轮需要的规则文件提供给支持附件阅读的大模型（如 ChatGPT / Claude / 豆包），对它说：**“使用 $ai-video-prompts 帮我写个打戏”**。让它读取规则后在后台推演，最后只交付能直接复制的、自足的白话纯文本提示词。
>
> 不支持文件夹上传时，按本轮任务上传需要的文件；新版规则分布在 `core/`、`ux/`、`visual/` 等目录，单传 `references/` 不是完整新版。缺模板再补 `assets/templates/` 对应文件，不必一次塞完整词库。普通聊天中的技能名称不能代替文件读取，先确认助手确实读到了规则。

**把一句灵感、打斗草稿或角色设定，整理成可以直接复制到视频生成平台的提示词。**

`ai-video-prompts` 从动作与打戏专长扩展到AI短片的灵感、剧本、视觉、镜头、声音、后期与交接管理。原有动作流程保留；新增方法按任务加载，不要求新手读完整规则。模块扩展不等于所有题材、平台和生成效果都经过实测。

最终默认交付**去标签、连贯、自足的白话提示词**。分段、接缝和动作负荷在内部检查；工程表仅在你主动要求查看时展示。视频制作由你选择的生成平台与后期工具完成。

## 快速开始

不用先读规则，直接选择一句话开口：

| 六个入口 | 示例 |
|---|---|
| 做新片 | 雨夜旧友决裂，先给两个方向 |
| 改稿精修 | 这段太文艺，改得日常一点 |
| 诊断成片 | 看这段哪里最先出错 |
| 学风格 | 帮我拆这张图的颜色和光 |
| 后期交付 | 帮我安排字幕、调色和输出 |
| 项目管理 | 整理版本和修改意见 |

纯问题也可以直接问。默认小白模式，后台规则不必读；只有主动索要才展开工程结构。

### 在 Codex 中安装

下载仓库并解压，将包含 `SKILL.md`、`core/`、`ux/`、各分层目录、`references/`、`assets/`、`scripts/` 的完整文件夹命名为 `ai-video-prompts`，放入以下位置之一：

| 安装范围 | 目录 |
|---|---|
| 个人使用 | `~/.agents/skills/ai-video-prompts/` |
| 只用于一个项目 | `<项目目录>/.agents/skills/ai-video-prompts/` |

Windows 个人目录通常对应 `%USERPROFILE%\.agents\skills\ai-video-prompts\`。确认最终路径是 `ai-video-prompts/SKILL.md`，避免解压后多套一层同名文件夹。安装位置及加载行为见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。

在对话中调用：

```text
$ai-video-prompts
一把剑和一杆枪在竹林中交手，5秒，3D写实国漫。
先给平台无关试做稿，只要能直接复制的提示词。
```

没有看到技能时，可重新打开 Codex 后检查。已有安装能正常识别时，更新那一份完整目录即可；避免保留多个同名副本。详细用法与任务路由见 [SKILL.md](SKILL.md)。

**日常使用技能无需运行 Python。** 下文辅助脚本按需使用。

## 可以怎样用

### 从模糊想法开始

```text
我只有“雨夜、旧友决裂”这几个词，先带我找灵感，不要直接给完整方案。
```

向导围绕世界观、空间、关系、奇观和核心动作收敛。灵感库含270项，每次展示5—6项；你可以说“换一批”“只看科幻”，也可以自由输入、跳过步骤或保留两条平行方案。

### 精修已有草稿

```text
把下面这段打斗草稿改成视频提示词。
保留人物关系、招式名、场景和结局，补清接触、发力和受击后的位移。
不要原文回贴，最后只给可复制的白话。
（接着粘贴你的草稿）
```

### 一次拿齐整套分段提示词

```text
目标30秒，接受分段生成。请一次给齐全部分段提示词。
每段都写完整角色锚点和起始状态，不用我自己拼固定前缀。
```

**一次拿齐文字，与平台一次生成整条视频是两个决定。** 实际段长按平台可选时长、动作复杂度与试片结果安排；内部事件单元不等于生成次数或剪辑次数。选择先试一段时，也只交所选试做范围。

### 加深对白与表演

```text
启用台词引擎和表演系统。
这句台词想试探旧友是否知情，但角色不愿暴露自己的暗伤。
请结合现场物件与动作改写，微相克制一点，不增加新剧情。
```

高级模块按明确请求或接受推荐后启用，不自动全部加载。推荐一次只提一项，连续两次未回应后停止主动推荐；你也可以直接说“别推荐，直接出提示词”。

### 找出成片最早出错的位置

```text
这是实际生成的视频、当时提交的提示词和设置。
请先找最早出现的身份、空间或接触错误，再给对应段落的修改稿。
```

诊断依据实际可见内容；没有听过音轨，就不判断音效或配音表现。

## 你会拿到什么

默认是每次实际提交对应的一段完整自然语言。必要的画风、人物、武器、场景、机位和起止状态已融入正文，不含 `G01`、`【必执行】`、工程时间段或剪辑指令。

下面是虚构人物的形式示例，未做视频生成实测：

```text
3D写实国漫，黑发束冠的青衣剑客持直剑，短发灰衣的枪手双手握长枪。竹林小径上，剑客在左、枪手在右，侧面中景看清兵器交汇和落脚。枪手向前踏步，枪尖刺向剑客胸前；剑客左脚斜跨半步，剑身斜贴枪杆，将枪尖引到身侧。枪手顺着枪杆偏转收枪，后撤一步，两人稳住脚步，重新隔开一段距离。
```

平台参数、参考图绑定和必要制作备注放在复制正文之外。只要你明确要求看图纸、检查分镜或接缝逻辑，才展开相应工程结构。

## 内部怎样把关

### 生成、控制、管理分层

| 层 | 放什么 | 去哪里 |
|---|---|---|
| 生成层 | 可见角色、空间、动作、摄影、接触反馈，以及本次已核实并采用的原生声音 | 语义转写后进入提示词正文 |
| 控制层 | 实际支持且本次使用的参考图、首尾帧、请求时长、分辨率等 | 平台对应参数位置 |
| 管理层 | 剪辑、选帧、变速、混音、复杂台词卡、QA与后期方案 | 独立制作备注 |

### 3+2与因果链

内部事件单元通常以约5秒起稿，最多3条必执行、2条氛围及2条针对性禁止；不用的项不凑满。它们是信息组织规则，不代表模型一定能完成三次攻防。

先判断是不是同一击的“逼近—交汇—受迫退开”，再判断是否拆分。同一条连续因果链可以合并描述，不按动词数机械切碎；新的独立攻击、复杂抓持与支撑转换仍要检查整次请求的负荷。具体规则见[模板契约](references/template-contract.md)。

禁止项在最终正文中转为肯定、可见的条件。例如，“禁止提前飞走”转为“掌根触及胸口后，对方才受力向后退开”，同时保留原本的对象与触发顺序。

### 台词与微相

- 台词从人物目的和当前现场出发，不为了套意象新增酒杯、旧债或秘密；题材措辞服从角色语言DNA。
- 约3—5秒镜头最多选一个主微相，配至多一个相关表演性肢体动作，优先复用原动作，不叠肌肉清单。
- 远景或大动作优先选择可读站位与身体信号；明确要求的脸部特写，改变方案前先取得用户选择。
- 义眼反馈要有既定义体设定；克制冷脸是表演选择，不是所有强烈情绪的统一模板。
- 复杂停顿、重音与潜台词解析进入后期备注。原生音效、对白和精准口型分别核实。

## 可选工具

三个脚本只用Python标准库，代码要求 **Python 3.8或以上**。脚本用于抽样、字段导出与模块结构检查，完整的动作判断和最终语义转写仍由助手完成。

以下命令从技能文件夹的**上一级目录**运行，目录关系如下：

```text
项目目录/
├── ai-video-prompts/   本仓库的完整文件
└── work/              运行历史和导出结果
```

先创建同级 `work`：

```bash
python -c "from pathlib import Path; Path('work').mkdir(exist_ok=True)"
```

### 抽取一批灵感

```bash
python -X utf8 ai-video-prompts/scripts/draw_inspiration.py --dimension world --count 6 --history work/inspiration-draws.json
```

指定古风子类：

```bash
python -X utf8 ai-video-prompts/scripts/draw_inspiration.py --dimension world --category 古风 --count 5 --history work/inspiration-draws.json
```

`--dimension` 可选 `world`、`space`、`relation`、`action`、`blind`、`mood`、`visual`、`archetype`；每批只能抽5或6张。历史记录帮助减少重复，应放在技能目录之外。

### 导出一个工程单元的纯文本底稿

```bash
python -X utf8 ai-video-prompts/scripts/export_prompt.py ai-video-prompts/examples/萧烬压境_填写示例.md --event G10 --output work/G10.txt
```

导出器会检查字段、空位与数量约束，并拒绝覆盖已存在的输出文件；它只做字段提取、去标签与拼句，**导出结果是底稿**。最终平台输入还需完成自然语言转写、禁止项正向表达和负荷判断，不能把机械拼句冒充最终提示词。默认对话交付会直接完成这一步，无需用户自行运行脚本。

调试时可用 `--format structured` 查看工程摘录。手写工程稿应遵守[主模板](assets/templates/生成输入模板.md)的字段和标记结构，避免无标签续行、重复字段或额外标题。若系统使用 `python3` 命令，可替换示例中的 `python`；安装在其他位置时改用相应路径。

### 检查模块组织（维护者可选）

```bash
python -X utf8 ai-video-prompts/scripts/validate_modules.py
```

检查头部字段、唯一ID、依赖/环、相对链接和入口可达性，不会自动修改文件；不代表真实视频效果或助手行为已测试。新模块不新增导出标记，原 `export_prompt.py` 解析逻辑保持。

新维度示例：`--dimension mood --category 压迫`、`--dimension visual --category 水墨`、`--dimension archetype --category 孤狼`；仍用同一个抽卡脚本和外置历史记录。

## 常见问题

**只有一句模糊想法，也能用吗？**

可以。先走灵感向导，默认按世界、空间、关系、奇观逐维拼装，一轮只问一维，支持自由输入与换批；“全由你定”也逐轮代选汇报。用户明确要求跳步或直接给完整方案时遵从；已有完整需求则直接执行，不重做问卷。

**必须提供参考图吗？**

可以选择无图流程，用可区分外观与清楚的起止状态起稿。有图时按实际上传素材分配职责；文字描述不等于严格身份锁定。

**能适配我用的视频平台吗？**

交稿前核对本次平台/模式、时长、实际参考素材、首尾帧和原生声音采用情况。功能不清楚时先给明确假设的草案，不编造参数，不固化某平台的时长上限。

**长对话换窗口怎么办？**

带上[继续创作状态卡](assets/templates/继续创作状态卡.md)与下一步必要文件。卡片记录已定设定、分支、平台条件、授权模块与接缝，不要求每轮把全库重新提供一遍。

## 验证与适用边界

当前本地运行环境为Windows、Python 3.14。本次改造执行模块组织、相对链接、依赖可达性、270项词库与八维抽卡、原导出示例对比；八个交互场景另作人工规则走查，不能等同独立助手实测。未为新增风格卡运行视频生成或后期软件流程。Python 3.8兼容性曾做语法与旧路径接口检查，尚未在实际3.8解释器或全部操作系统上逐一运行。

这些检查验证文件组织和本地工具，不代表所有助手都稳定遵守全部规则，也不保证视频模型的身份、复杂接触、微相、精确时长或口型效果。不同平台与输入方式仍需实际试片；仅看分镜或静态帧，不能宣布动态效果、音效和剪辑衔接已经通过。

## 情境细节默认处理

剧情与当前场次确定后，助手会按人物状态、已有物件、天气材质和叙事视角，少量融入生活动作、道具纹理、受力反馈与主观镜声，不需要逐项开启，也不附“已加载某模块”的说明。它不会把词库词条机械套进每场戏。

这些细化复用原动作或共用原氛围额度，3+2不放宽；新的摔倒、失明、取物、损毁等独立事件不能当氛围免费加入。生活与道具表演整场最多一个角色一个新增小动作，可以不加。改变人物身份、关键道具、剧情结果，或深挖台词/心理卡仍沿用原有明确范围；静止、极简与既定资产优先。

新增入口：[生活微动作](narrative/life-actions.md) · [环境干预](visual/environment-interaction.md) · [主观镜语](production/camera-and-rhythm.md) · [道具叙事](narrative/prop-storytelling.md)。主观镜语是增量页，原references运镜路径保留；所有输出仍默认自足白话。原生声音与后期精确处理按实际平台能力分开，不承诺未做过的生成效果。
